# FFX Player — Downloads

Instaladores oficiais do FFX Player para Windows.

> Simples quando você quer. Poderoso quando precisa.

## Versão atual

### FFX Player 1.0.39

[Baixar o instalador diretamente](https://github.com/tecmabeinformatica/ffx-player-releases/raw/refs/heads/main/FFXPlayer-Setup-1.0.39.exe)

- Plataforma: Windows x64.
- Sistemas: Windows 10 versão 2004 ou superior e Windows 11.
- Instalação: Inno Setup 6, pacote independente do .NET Runtime.
- SHA-256: `D21C4C491BFF599230E3F5DF98C137B2CF7B23FEF5840ED1E60E805A827253B2`

## Novidades da versão 1.0.39

- Atalhos `G/H` para adiantar ou atrasar legendas em passos de 50 ms.
- Atalhos `J/K` para adiantar ou atrasar o áudio em passos de 50 ms.
- `Ctrl++` e `Ctrl+-` para ajustar o tamanho das legendas.
- `Ctrl+0` para restaurar o tamanho original das legendas.
- Balões de ajuda nas configurações indicando os atalhos de sincronização.

## Principais recursos

- Reprodução universal de áudio e vídeo com libmpv.
- Playlist, sequência automática da pasta, shuffle e repeat.
- Mini player persistente.
- Tela cheia com controles ocultados automaticamente.
- Seleção de áudio, legendas e proporção.
- Equalizador de 10 bandas com presets.
- Pass-through de áudio e fallback para formatos incompatíveis.
- Retomada de vídeos longos.
- Sincronização de áudio e legendas.
- Detecção HDR para Windows 10 e 11, com indicação de HDR nativo ou conversão HDR para SDR.
- Interface em Português (Brasil) e Inglês.
- Associação opcional de formatos de mídia durante a instalação.
- Sem anúncios, cadastro ou telemetria.

## Instalação

1. Baixe `FFXPlayer-Setup-1.0.39.exe`.
2. Execute o instalador.
3. Se desejar, marque a opção final para abrir as configurações de aplicativos padrão do Windows.

O instalador ainda não possui assinatura digital comercial. Dependendo das configurações do Windows, o SmartScreen pode solicitar confirmação antes da execução.
